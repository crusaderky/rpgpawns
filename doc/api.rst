Constants
---------

.. autodata:: rpgpawns.pawn.DPI
   :no-value:

   Output resolution in dots per inch (300).

.. autodata:: rpgpawns.pawn.MAX_WIDTH_MM
   :no-value:

   Maximum pawn width in millimetres (28).

.. autodata:: rpgpawns.pawn.MAX_HEIGHT_MM
   :no-value:

   Maximum single-image height in millimetres (48).

.. autodata:: rpgpawns.pawn.PADDING_MM
   :no-value:

   White padding added at the top and bottom of each pawn in millimetres (4).

.. autodata:: rpgpawns.pawn.COLLAGE_MAX_PAWNS
   :no-value:

   Maximum number of pawns that fit on a single A4 page (10).

.. autodata:: rpgpawns.pawn.COLLAGE_COLS
   :no-value:

   Number of columns in the A4 collage grid (5).

.. autodata:: rpgpawns.pawn.COLLAGE_ROWS
   :no-value:

   Number of rows in the A4 collage grid (2).
